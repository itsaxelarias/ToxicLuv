# Web

Web beta workspace for Toxicmetter.

## Beta Direction

Recommended stack:

- React
- TypeScript
- Vite
- OCR support through an API or browser-compatible worker
- Responsive layout for mobile-first testing
- Shared API contract with the Android and iOS versions

## First Screens

1. Welcome and privacy note
2. Account or private start
3. Analysis mode picker
4. Pattern tree flow
5. Result summary
6. Safety resources
