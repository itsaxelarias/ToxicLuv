# Android

Native Android beta workspace for ToxicLuv.

## Beta Direction

Recommended stack:

- Kotlin
- Jetpack Compose
- Camera and gallery imports for screenshots
- Local encrypted storage for sensitive sessions
- Shared API contract with the web and iOS versions

## First Screens

1. Welcome and privacy note
2. Account or private start
3. Analysis mode picker
4. Pattern tree flow
5. Result summary
6. Safety resources

## Analysis Modes

- Real-time chat
