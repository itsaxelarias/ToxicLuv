# iOS

Native iOS beta workspace for ToxicLuv.

## Beta Direction

Recommended stack:

- Swift
- SwiftUI
- Photos picker for screenshots
- Vision OCR for image text extraction where possible
- Keychain and encrypted local storage for sensitive sessions
- Shared API contract with the Android and web versions

## First Screens

1. Welcome and privacy note
2. Account or private start
3. Analysis mode picker
4. Pattern tree flow
5. Result summary
6. Safety resources

## Analysis Modes

- Real-time chat
- Pattern tree
- Exported chat
- Screenshots and images
